# 🦾 Cybertron — AI Workspace

## 🚀 Key Features

* **Advanced AI Chat & Reasoning**: Powered by ultra-fast Groq API with real-time web grounding via Tavily API.
* **AI Image Generation**: Integrated with authenticated Pollinations.ai endpoint for instant, high-quality image rendering directly inside the workspace.
* **Voice-to-Voice Interaction**: Built-in browser Web Speech API for voice-to-text dictation and speech synthesis.
* **Document & PDF Analysis**: Upload documents to let the AI process and answer queries based on your files.
* **Secure Chat History**: Seamless Google OAuth authentication via NextAuth.js paired with MongoDB Atlas to persist session history securely.
* **Mafia / Cyberpunk UI/UX**: High-contrast, dark obsidian and neon-accented custom design with smooth interactions and responsive layouts.

---

## 🛠️ Tech Stack

* **Frontend**: Next.js 14+ (App Router), React, Tailwind CSS, Lucide Icons.
* **Backend**: Next.js API Routes, Mongoose, NextAuth.js.
* **AI & Services**: Groq SDK, Pollinations.ai API, Tavily API.
